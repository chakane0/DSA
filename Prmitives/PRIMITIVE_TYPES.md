# Primitive Types

These are the basic types in java


   Type | Size| Range
1. byte | 1 | -128 to 127
2. short | 2 | -32768 to 32767
3. int | 4 | -2147473648 to 2147473647
4. long | 8 | ---
5. float | 4 | +/- 3.4E +/- 38
6. double | 8 | +/- 1.7E +/- 308
7. char | 2 | 065535
8. boolean | ? | true/false

#### Tips
1. Be comfortable with bitwise operators, XOR in particular
2. Understand how to use masks and create them in a machine independent way
3. Be able to clear the lowest set bit
4. Understand signedness and implication to shifting
5. Be aware that commutativity and associativity can be used to perform operations in parallel and reorder operations
